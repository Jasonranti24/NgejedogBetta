# NgejedogBetta 🐟

Website penjualan ikan cupang — katalog, filter, keranjang, dan checkout lewat WhatsApp.

## ✨ Fitur

- Katalog 7 jenis ikan cupang dengan foto dan deskripsi
- Filter berdasarkan jenis dan harga
- Keranjang belanja
- Checkout langsung lewat WhatsApp

## 🚀 Cara pakai

Buka `index.html` di browser — tidak perlu build step atau server. Bisa juga
di-deploy ke GitHub Pages, Netlify, atau Vercel apa adanya.

## 🛠️ Teknologi

- HTML + CSS + JavaScript (single file, tanpa framework)
- Semua aset sudah inline di `index.html`

## ⚠️ Catatan

Nomor WhatsApp, harga, stok, dan testimoni di website ini masih **data contoh**.
Ganti dengan data asli sebelum dipakai jualan beneran.
